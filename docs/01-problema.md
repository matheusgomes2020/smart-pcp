
# Problemas Atuais

## Contexto

As informações necessárias para o acompanhamento da produção encontram-se distribuídas em diferentes módulos do ERP Delta, exigindo diversas consultas para compreender completamente a situação de um pedido.

## Problemas Identificados

### PCP

- Necessidade de navegar entre diversas telas.
- Dificuldade para acompanhar o andamento dos pedidos.
- Priorização realizada manualmente.
- Dependência de consultas à produção para obter informações atualizadas.
- Dificuldade para prever prazos de entrega.

### Produção

- Apontamentos descentralizados.
- Baixa visibilidade dos gargalos.
- Dificuldade em acompanhar o histórico dos processos.

### Compras

- Baixa integração entre compras e produção.
- Dificuldade para identificar materiais críticos.

### Gestão

- Indicadores limitados.
- Pouca visibilidade da produção em tempo real.
