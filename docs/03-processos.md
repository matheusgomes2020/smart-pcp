
# Objetivos

## Objetivo Geral

Desenvolver uma plataforma integrada de apoio ao Planejamento e Controle da Produção (PCP), consolidando informações do ERP Delta em uma interface única.

## Objetivos Específicos

- Centralizar informações dos pedidos.
- Acompanhar o andamento da produção.
- Automatizar a definição de prioridades.
- Identificar gargalos produtivos.
- Melhorar a comunicação entre os setores.
- Gerar indicadores para tomada de decisão.
- Disponibilizar previsões de entrega.
- Servir como base para futuras funcionalidades utilizando Inteligência Artificial.
